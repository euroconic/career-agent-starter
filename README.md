# Career Agent Starter

Чистый репозиторий карьерного AI-ассистента для одного человека. Помогает оценивать вакансии, готовить CV, разбирать интервью и вести отклики. В поставке нет чужого профиля, резюме, переписки или истории поиска.

## Начать

1. Распакуйте архив в отдельную папку или клонируйте [репозиторий шаблона](https://github.com/euroconic/career-agent-starter): `git clone https://github.com/euroconic/career-agent-starter.git`.
2. Откройте эту папку в AI-агенте с доступом к локальным файлам.
3. Отправьте ему:

```text
Прочитай AGENTS.md и ONBOARDING.md. Проведи меня через онбординг этого
карьерного проекта. Используй только мои ответы и мои документы.
Задавай вопросы небольшими группами. Не придумывай опыт и достижения.
После настройки помоги разобрать первую вакансию.
```

Альтернатива: `python3 tools/onboard.py` запускает локальную анкету. Нужен Python 3.10 или новее, сторонние пакеты не требуются. Скрипт не вызывает AI и не отправляет данные в сеть. При отсутствии Python агент может создать файлы по инструкции [ONBOARDING.md](ONBOARDING.md).

## Что внутри

| Задача | Навык |
|---|---|
| Оценка вакансии | `skills/job-vacancy-analysis/` |
| Подготовка и обновление CV | `skills/job-application-cv/` |
| Сравнение готовых CV с вакансией | `skills/ats-cv-fit-review/` |
| Краткий разбор интервью | `skills/interview-transcript-analysis/` |
| Разбор интервью по вопросам | `skills/interview-deep-analysis/` |
| Проверка отчёта по исходникам | `skills/verify/` |

`CLAUDE.md` содержит маршрутизацию задач. В `.claude/commands/` есть адаптеры команд. Если ваш агент не обнаруживает навыки автоматически, укажите ему точный путь к `SKILL.md`. Глобальная установка или доступ к аккаунтам для начала работы не нужны.

## После настройки

- «Оцени вакансию из `vacancies/role.md` по моему профилю. Пока ничего не сохраняй».
- «Подготовь CV под эту роль и сохрани материалы в `applications/company__role/`. Не отправляй отклик».
- «Разбери интервью из указанного файла и предложи три упражнения».
- «Проверь этот отчёт по исходному транскрипту».

Пустые поля и отсутствие CV означают, что данных пока нет. Шаблоны не являются подтверждёнными карьерными фактами. AI работает через выбранного вами агента; его доступ к файлам и условия обработки данных определяются используемым сервисом.

## Личные данные и передача клиентам

Одна копия проекта предназначена для одного человека. Онбординг создаёт `about.md`, `voice.md`, `inputs/`, `memory/`, `applications/` и `config/`. Эти пути исключены из Git. Это защита от обычного случайного коммита, а не шифрование и не резервная копия.

Для следующего клиента передавайте исходный чистый архив или создавайте новый:

```sh
python3 tools/doctor.py --template
python3 tools/export_template.py --output ../career-agent-starter.zip
```

Экспорт берёт только файлы из `template-manifest.json`, не включает `.git`, личные рабочие папки, ключи и локальные настройки. Он не перечитывает и не обезличивает CV. Если вы внесли личные сведения прямо в инструкции шаблона, сначала удалите их: автоматическая проверка не доказывает отсутствие всех персональных данных.

Git-история этой поставки начинается с чистого состояния. Публичный репозиторий содержит только общий шаблон. После клонирования не отправляйте личные данные в исходный репозиторий; для собственных изменений шаблона используйте свою отдельную копию.

## Проверки

```sh
python3 tools/doctor.py --template
python3 -m unittest discover -s tests -v
python3 -m unittest discover -s tools/workspace -p 'test_*.py' -v
python3 -m unittest discover -s skills/job-application-cv/evals -p 'test_*.py' -v
```

После онбординга: `python3 tools/doctor.py --workspace`. Для проверки трекера: `python3 tools/workspace/pipeline_check.py --check-files`.

Это файловый проект для работы с AI-агентом. Веб-сервис, платёжная система, личный кабинет и чужие облачные интеграции в эту поставку не входят. Создание и визуальная проверка Word/PDF требуют соответствующих инструментов в среде агента; без них доступен Markdown-черновик.
